# demo-vidriero

Demo estática de TuWebEn3Dias para el rubro vidriería. Está construida en un único `index.html`, sin dependencias ni compilación, y funciona tanto en la raíz como en el subdirectorio de GitHub Pages.

## Alcance de la demo

- Marca, ubicación, cobertura, contacto e imágenes de trabajo son ilustrativos o ficticios.
- No hay envío ni almacenamiento de formularios; al enviarlo, solo aparece una aclaración en pantalla.
- Los paneles visuales de la galería son ilustraciones SVG creadas para esta demo.
- Reemplazar la información y configurar un canal de contacto real antes de adaptar el sitio a un negocio.

## Publicar con GitHub Pages

En el repositorio, activar Pages desde `Settings → Pages` y seleccionar `Deploy from a branch`, rama `main`, carpeta `/ (root)`. La entrada pública será `index.html`.
